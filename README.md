Domain
========

This is currently a beta release. We are finding that the module generally seems 
to work, but it needs more testing before we can assume it's stabile. Please, 
test it out and report bugs. But, be cautious before installing in a 
production environment. 

Documentation
-------------------
Please review the documentation in the wiki and help us make it better. 
https://github.com/backdrop-contrib/domain/wiki


Installation
------------
- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.
- This module requires modifications to the settings.php file. Be sure to review:
  https://github.com/backdrop-contrib/domain/wiki/2.-Domain-Quick-Start-Install

Issues
